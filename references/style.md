# 原位抠图转场：参考拆解

参考：[Muse Instagram DUlgN1TjDKn](https://www.instagram.com/p/DUlgN1TjDKn/)，2026-10-05 用已登录 Chrome 读取并抽取正片帧。参考用于方法分析；分享包不含该视频、截图或原音乐。

## 真正需要复刻的机制

正片 720×1280，时长约15秒。前12.8秒为密集旅行照片蒙太奇，最后是黑底小字 CTA。常见一轮照片接管约0.4–0.65秒，但不是经过音频分析得到的精确节拍。

在时间 T 前约0.2–0.4秒，照片 B 的透明前景先出现在照片 A 上；T 时背景直接变为完整 B，前景本身保持原坐标。随后轮到 C。不是整图交叉溶解、白边贴纸、随机飞入或主体放大。工具默认将前景提前量收敛为0.2秒（30 fps 下约6帧），并限制为不超过前一张照片时长的一半，避免主体过早叠上使画面显得拥挤。

PNG 必须保留原图整个画布和原像素尺寸；Photo 和 Cutout 用一致的 `object-fit: cover`、`object-position` 与调色。不能 tight-crop mask 后再居中，也不能分别做 Ken Burns 导致在接管帧跳动。

主体不只人像，还包括斑马、企鹅、建筑、棕榈、船、伞、盘子、沙丘边缘及多主体岛。Vision 的 foreground instances 比仅人像抠图更贴合，但复杂建筑/风景仍可能失败。允许整图切换或提供手工 mask；失败不能伪称抠图成功。

## 节奏预设

`reference` 每张一拍，在已知100 BPM 的网格上为0.6秒；`breathing` 以一拍、两拍交替，即0.6、1.2秒。这是两种剪辑预设，不是对原曲 BPM 的识别，也不是根据人像或画面复杂度自动选择停留时长。按具体画面和真实音乐需要，可逐张编辑 `job.json`。

四张图的两版节奏短样分别只有2.4秒和3.6秒，不含可选结尾。做长片应增加新的照片，让镜头更新维持密度；不要单纯延长每张画面来凑长度。用户明确需要均匀慢节奏时，仍可用 `--seconds-per-photo` 或 `--beats-per-photo` 覆盖预设。结尾 CTA 始终可选。

## 视觉约束

- 全幅摄影，主体透明边缘自然，无白色描边。
- 默认保留原图位置，没有旋转、弹跳和浮动。
- 暖色、轻低饱和的摄影质感；以实际素材的肤色和曝光为准。
- 可选小号居中衬线字，内容贯穿多镜头；不强制放品牌水印或广告 CTA。
- 参考音乐没有取样/识别。自选、原创预览音乐或合法可用音乐可替换，不能称原曲复刻。

## 验收

检查 T−leadIn/2（看到 B 前景+A 背景）、T（完整 B）、T+一帧（不闪烁），同时检查人物位置和颜色是否相同。全片不得有非预期黑帧、矩形假抠图、原图/主体错位。多画幅必须各自检查，转换比例不等于完成构图。
