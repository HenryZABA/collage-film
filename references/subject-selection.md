# 逐图确定主体

“自动去背景”和“选对主体”是两个任务。BiRefNet 预测显著前景；SAM 2 根据框和点分割对象。当前语义判断由使用 Skill 的视觉 Agent 完成，并非 SAM 2 自动理解文字。`subject` 是可审查的意图记录，不会作为虚假的文字分割参数传入模型。

## 从图像到对象计划

先实际查看经过 EXIF 旋转的原图，确定人物、动物、产品、建筑轮廓或若干共同构成画面的对象。写清应排除的路人、倒影、岩石、桌面等。普通显著前景先用 BiRefNet；指定其中一只杯子、多人中的某一人、小动物混在石头中等情况，用 SAM 2。

框应包住对象全部可见部分，包括手提包、杯把、脚尖；不要因为想保留一只杯子而把旁边杯子也框入。包含点落在对象内部，排除点落在背景或干扰对象内部。多个对象分别提示、分别分割，最后合并；不要只留最大连通区域，这会删除腿间分离部分、伞杆、第二只动物等。模型没有生成被遮挡的部分，不能称完整恢复。

每个坐标均在 EXIF 归正的全尺寸图上定义，以左上为原点并归一化到 0–1。`box` 为 `[left,top,right,bottom]`，`points` 每项为 `[x,y,label]`，label=1 包含、0 排除。直接抠一张图时：

```json
{
  "subject": "只保留前面的白色咖啡杯及杯把；排除后杯、手和桌面",
  "objects": [
    {"box": [0.32, 0.43, 0.98, 0.86], "points": [[0.55, 0.70, 1], [0.52, 0.40, 0]]}
  ]
}
```

以上数值仅用于咖啡测试照片，不能复制给任意图片。执行 `cutout.py PHOTO --backend sam2 --selection-file selection.json --no-crop --output-dir cutouts`。没有明确几何提示会直接报错，不会退回把所有物体都抠出。

## 批量制作视频

`make.py --subjects subjects.json` 为每张照片选择后端和对象。序号按 `--images` 的原始顺序、从1开始。SAM 2 条目必须包含所看原片的 SHA-256，防止照片替换或排序后静默使用错误提示；工具会核对。

```json
{
  "schema_version": 1,
  "images": [
    {"index": 1, "subject": "前景人像，保留头发和手提包", "backend": "birefnet"},
    {
      "index": 2,
      "subject": "只保留前面的杯子",
      "backend": "sam2",
      "refine": "auto",
      "source_sha256": "替换为所看原图的64位SHA-256",
      "objects": [{"box": [0.32, 0.43, 0.98, 0.86], "points": [[0.55, 0.70, 1]]}]
    }
  ]
}
```

未列入计划的照片使用全局 `--backend`。`--skip-cutout` 与同一照片的对象计划不能并存。Vision 可用 `backend: "vision", instances: "1,2"` 选择它已检测到的实例，但实例编号不是语义、也不是置信度排名；当 Vision 合并或漏检对象时，换到 SAM 2。

## 反馈闭环

每次检查“选对对象”再检查“边缘”。在全图与局部放大中看：身体/杯身是否挖空，孔洞是否残留背景，脚/细杆是否消失，邻近同色物体是否混入。一次只改明确有问题的框或点，最多做三次针对性修订；仍不合格时保留失败证据并说明需要更强模型或修正 mask，不能把失败包装成成功。明确采用整图切换时应记录为剪辑选择，而非抠图通过。

SAM 2 负责对象选择。配置 ViTMatte 后，默认 `refine: "auto"` 生成 trimap 并精修边缘；可选 `none` 或显式要求 `vitmatte`。杯沿和杯把孔在测试中改善，细发丝、透明玻璃和运动模糊仍需单独检查。棕榈叶间已经被判为确定前景的天空残留，不能靠边缘精修自动纠正；先修 mask/提示，仍不合格就标失败。不要整图再跑一个自动前景模型并声称它受 SAM 约束，也不要以简单 mask 交集/并集代替正确的 alpha matting。
